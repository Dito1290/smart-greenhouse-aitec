BAGIAN 2: RINGKASAN EKSEKUTIF
--------------------------------------------------------------------------------

LATAR BELAKANG MASALAH:
Pertanian greenhouse konvensional menghadapi tantangan dalam pemantauan dan 
pengendalian parameter lingkungan (suhu, kelembapan udara, kelembapan tanah, 
intensitas cahaya) yang optimal untuk pertumbuhan tanaman. Sistem manual 
memerlukan tenaga kerja intensif, rentan terhadap human error, dan tidak mampu 
merespons perubahan kondisi lingkungan secara cepat. Hal ini menyebabkan 
pemborosan air irigasi hingga 40%, konsumsi energi yang tidak efisien, dan 
fluktuasi produktivitas hingga 30% akibat kondisi mikroklimat yang tidak stabil.

SOLUSI TEKNOLOGI:
Proyek ini mengembangkan sistem Smart Greenhouse terintegrasi berbasis 
mikrokontroler ESP32 dengan kemampuan:
1. Monitoring real-time parameter lingkungan (suhu, kelembapan udara/tanah, 
   intensitas cahaya) melalui jaringan sensor presisi tinggi
2. Kontrol otomatis aktuator (pompa irigasi, exhaust fan, sistem pencahayaan) 
   berdasarkan threshold adaptif sesuai kebutuhan tanaman
3. Komunikasi data ke cloud server menggunakan protokol MQTT dengan dashboard 
   monitoring berbasis web/mobile yang dapat diakses dari mana saja
4. Sistem logging data historis untuk analisis tren dan pengambilan keputusan
5. Alert system untuk notifikasi kondisi abnormal

KEUNGGULAN & NOVELTY:
- Integrasi multi-sensor dengan single board ESP32 yang hemat energi
- Algoritma kontrol adaptif berbasis threshold dinamis per fase pertumbuhan
- Arsitektur modular dan scalable untuk ekspansi sensor tambahan
- Biaya implementasi terjangkau (<Rp 2.500.000 per unit greenhouse 50m²)
- Open-source dan replicable untuk transfer teknologi ke petani

DAMPAK YANG DIHARAPKAN:
- Peningkatan efisiensi penggunaan air hingga 45% melalui irigasi presisi
- Reduksi tenaga kerja pemantauan manual hingga 70%
- Stabilisasi parameter mikroklimat dengan standar deviasi <5% dari target
- Peningkatan produktivitas tanaman 20-35% melalui kondisi optimal konsisten
- ROI (Return on Investment) tercapai dalam 8-12 bulan operasional

TARGET KOMODITAS:
Fase pilot untuk tanaman sayuran daun (selada, kangkung, pakcoy) dengan 
potensi ekspansi ke tomat, paprika, dan tanaman hortikultura bernilai tinggi.

BAB 1: PENDAHULUAN

1.1 LATAR BELAKANG

Sektor pertanian Indonesia menghadapi tantangan kompleks di era modernisasi: 
kebutuhan peningkatan produktivitas, efisiensi sumber daya, dan adaptasi 
terhadap perubahan iklim. Greenhouse (rumah kaca) merupakan solusi controlled 
environment agriculture yang memungkinkan produksi tanaman berkualitas tinggi 
sepanjang tahun. Namun, pengelolaan greenhouse konvensional menghadapi kendala:

A. Pemantauan Manual yang Tidak Efektif
   - Monitoring parameter lingkungan dilakukan 2-3 kali per hari secara manual
   - Tidak ada data kontinyu untuk mendeteksi fluktuasi mikroklimat
   - Ketergantungan pada penilaian subjektif petani

B. Kontrol yang Tidak Presisi
   - Irigasi berbasis jadwal tetap tanpa mempertimbangkan kondisi aktual tanah
   - Ventilasi manual yang lambat merespons perubahan suhu/kelembapan
   - Overapplication air dan energi menyebabkan biaya operasional tinggi

C. Keterbatasan Akses Informasi Real-Time
   - Petani tidak dapat memantau kondisi greenhouse dari jarak jauh
   - Tidak ada sistem peringatan dini untuk kondisi abnormal (overheating, 
     kekeringan, kelembapan ekstrem)
   - Data historis tidak tercatat untuk pembelajaran dan optimasi

D. Hambatan Adopsi Teknologi
   - Sistem otomasi komersial terlalu mahal (>Rp 50 juta per greenhouse)
   - Kompleksitas instalasi dan maintenance memerlukan expertise tinggi
   - Ketergantungan pada vendor proprietary untuk support

Berdasarkan studi FAO (2024), implementasi precision agriculture pada greenhouse 
dapat meningkatkan water use efficiency hingga 40-60% dan produktivitas 25-45%. 
Namun, adopsi di Indonesia masih <5% karena kendala biaya dan aksesibilitas 
teknologi.

1. Mampu memonitor parameter lingkungan kritis secara real-time dan kontinyu

3. Menyediakan interface user-friendly untuk monitoring dan manajemen jarak jauh
4. Terjangkau secara ekonomis untuk skala usaha kecil-menengah (UMKM pertanian)
5. Mudah direplikasi dan di-maintain oleh petani dengan pelatihan minimal

BAB 2: TINJAUAN PUSTAKA DAN KEBARUAN SISTEM

2.1 LANDASAN TEORI

A. Parameter Lingkungan Optimal Tanaman Hortikultura

Berdasarkan literatur (Jones, 2014; Nemali & van Iersel, 2006), parameter 
kritis untuk pertumbuhan tanaman sayuran daun di greenhouse:

1. Suhu Udara
   - Range optimal: 20-28°C (fase vegetatif)
   - Suhu >32°C menyebabkan heat stress dan penurunan fotosintesis
   - Suhu <15°C menghambat pertumbuhan dan memperpanjang siklus panen

2. Kelembapan Udara (Relative Humidity)
   - Range optimal: 60-80%
   - RH >85% meningkatkan risiko penyakit jamur (powdery mildew, downy mildew)
   - RH <50% menyebabkan excessive transpiration dan stress air

3. Kelembapan Tanah (Soil Moisture)
   - Range optimal: 60-80% kapasitas lapang (field capacity)
   - Deficit air >20% menyebabkan wilting dan penurunan turgor
   - Saturasi >90% menghambat aerasi akar dan meningkatkan risiko root rot

4. Intensitas Cahaya
   - Minimum untuk fotosintesis: 200 µmol/m²/s (≈10,000 lux)
   - Optimal untuk sayuran daun: 300-600 µmol/m²/s (15,000-30,000 lux)
   - DLI (Daily Light Integral) target: 12-17 mol/m²/day

B. Teknologi IoT untuk Precision Agriculture

Internet of Things (IoT) mengintegrasikan sensing, computation, dan communication 
untuk sistem cyber-physical pertanian (Wolfert et al., 2017). Komponen utama:

1. Sensor Layer: Akuisisi data lingkungan menggunakan transduser elektronik
2. Edge Computing: Preprocessing dan kontrol lokal pada mikrokontroler
3. Network Layer: Transmisi data via WiFi/LoRa/NB-IoT ke gateway/cloud
4. Cloud Platform: Storage, analytics, dan presentation layer
5. Application Layer: Dashboard, alert, dan decision support system

C. Mikrokontroler ESP32 untuk Aplikasi Greenhouse

ESP32 (Espressif Systems) merupakan SoC (System-on-Chip) dengan keunggulan:
- Dual-core Xtensa LX6 @ 240MHz untuk multitasking
- WiFi 802.11 b/g/n dan Bluetooth 4.2 terintegrasi
- 18 channel 12-bit ADC untuk interfacing sensor analog
- GPIO sufficient untuk multiple sensor/actuator
- Deep sleep mode (<100µA) untuk aplikasi battery-powered
- Biaya rendah (~$5 per unit) dan ekosistem open-source mature

D. Protokol Komunikasi IoT: MQTT

MQTT (Message Queuing Telemetry Transport) adalah protokol publish-subscribe 
yang ideal untuk IoT karena:
- Lightweight (minimal overhead, efisien untuk bandwidth terbatas)
- Quality of Service (QoS) levels untuk reliability
- Persistent sessions dan retained messages
- Support untuk TLS/SSL encryption
- Broker open-source tersedia (Mosquitto, HiveMQ)


2.2 STATE-OF-THE-ART SISTEM GREENHOUSE AUTOMATION

Review sistem existing:

A. Komersial High-End (Priva, Ridder, Hoogendoorn)
   - Kelebihan: Fully integrated, AI-based climate control, proven reliability
   - Kekurangan: Biaya tinggi (>$10,000), proprietary, maintenance cost
   - Gap: Tidak accessible untuk smallholder farmers

B. DIY/Open-Source (FarmBot, Open Agriculture Initiative)
   - Kelebihan: Terjangkau, customizable, community-driven
   - Kekurangan: Limited support, complex assembly, reliability varies
   - Gap: Fokus pada hobbyist, kurang robust untuk produksi komersial

C. Penelitian Akademis (IEEE, ScienceDirect papers)
   - Berbagai studi proof-of-concept menggunakan Arduino/Raspberry Pi
   - Fokus pada aspek teknis tertentu (sensor accuracy, control algorithm)
   - Gap: Jarang mencapai tahap field deployment dan economic viability analysis


2.3 KEBARUAN DAN KEUNGGULAN SISTEM YANG DIUSULKAN

Sistem Smart Greenhouse yang dikembangkan memiliki novelty:

A. Arsitektur Terintegrasi Hemat Biaya
   - Single ESP32 board menggantikan multiple controller/gateway
   - PCB custom untuk reliable connection dan industrial-grade durability
   - Total BOM (Bill of Materials) <Rp 2.000.000 untuk sistem lengkap

B. Algoritma Kontrol Adaptif
   - Threshold dinamis berdasarkan fase pertumbuhan (seedling, vegetative, harvest)
   - Time-based rules untuk menghindari actuator cycling
   - Hysteresis control untuk stabilitas sistem

C. Cloud Platform Terintegrasi
   - Dashboard real-time dengan visualisasi time-series data
   - Historical data analytics untuk yield prediction
   - Mobile app untuk remote monitoring dan control
   - Export data untuk further analysis (CSV, API)

D. Pendekatan Participatory Design
   - Co-design dengan petani untuk memastikan usability
   - Training dan dokumentasi dalam Bahasa Indonesia
   - Local support network untuk sustainability

E. Economic Viability
   - Analisis ROI berdasarkan water savings dan yield increase
   - Scalable deployment model (per-greenhouse unit)
   - Open-source untuk replikasi dan customization

BAB 3: METODE PELAKSANAAN
================================================================================

3.1 DESAIN SISTEM

A. Arsitektur Hardware (lihat file hardware/architecture.txt)

Komponen Utama:
1. Mikrokontroler: ESP32 DevKit v1 (30-pin)
2. Sensor:
   - DHT22 / SHT31: Suhu dan kelembapan udara
   - Soil Moisture Sensor (Capacitive): Kelembapan tanah
   - BH1750 / LDR + resistor: Intensitas cahaya
3. Aktuator:
   - Relay 4-channel 5V (untuk pompa, fan, lampu, spare)
   - Water pump DC 12V 3-5L/min
   - Exhaust fan 12V 0.15A
   - LED grow light 12V (optional)
4. Power Supply:
   - Adaptor 12V 3A untuk aktuator
   - Step-down converter 12V→5V 3A untuk ESP32 dan sensor
5. Enclosure:
   - IP55 junction box untuk ESP32 dan relay
   - Weatherproof sensor housing

B. Arsitektur Software

1. Firmware ESP32 (Arduino framework):
   - Sensor reading dengan error handling
   - Control logic berbasis threshold dan timer
   - MQTT client untuk publish data dan subscribe commands
   - OTA (Over-The-Air) update capability
   - Watchdog timer untuk system resilience

2. Cloud Backend:
   - MQTT Broker: Mosquitto di VPS/cloud server
   - Time-series database: InfluxDB untuk sensor data
   - Application server: Node.js + Express untuk API
   - Authentication: JWT-based user management

3. Frontend Dashboard:
   - Web app: React.js dengan Chart.js untuk visualization
   - Responsive design untuk mobile access
   - Real-time update via WebSocket/MQTT over WebSocket

3.3 METODE PENGUJIAN

A. Pengujian Hardware
1. Continuity test untuk semua koneksi kabel
2. Voltage level verification pada power rail (3.3V, 5V, 12V)
3. Sensor functionality test dengan known reference conditions
4. Actuator load test untuk durability dan thermal performance

B. Pengujian Software
1. Unit testing untuk fungsi sensor reading dan control logic
2. Integration testing untuk MQTT communication flow
3. Stress testing untuk system uptime dan recovery dari disconnect
4. User acceptance testing dengan end-user (petani)

C. Pengujian Sistem Terintegrasi
1. Closed-loop control test: Verifikasi bahwa system merespons perubahan 
   environment dan mengaktifkan actuator sesuai threshold
2. Data accuracy test: Perbandingan sensor reading dengan instrument reference
3. Latency test: Measuring response time dari sensor trigger hingga actuator action
4. Long-term reliability test: Continuous operation 7x24 jam untuk monitoring 
   failure rate

D. Evaluasi Efektivitas
1. Baseline measurement: Data kondisi greenhouse manual selama 1 minggu
2. Automated operation: Data dengan Smart Greenhouse selama 2-3 minggu
3. Metrics comparison:
   - Water consumption (liter/hari)
   - Energy consumption (kWh/hari)
   - Parameter stability (standard deviation suhu, RH, soil moisture)
   - Labor hours untuk monitoring/maintenance
4. Economic analysis: Payback period calculation


3.4 LOKASI DAN SUBJEK

Lokasi Penelitian:
- Greenhouse pilot project di [Nama Lokasi, misal: Kebun Percobaan Universitas 
  atau Greenhouse UMKM mitra]
- Dimensi: 6m x 8m x 3m (48 m² growing area)

Tanaman Pilot:

PENUTUP

Sistem Smart Greenhouse berbasis ESP32 yang diusulkan menawarkan solusi 
praktis, terjangkau, dan scalable untuk mengadopsi precision agriculture di 
Indonesia. Dengan memanfaatkan teknologi IoT open-source, sistem ini dapat 
menjadi model transfer teknologi yang sustainable dan memberikan dampak nyata 
pada peningkatan produktivitas dan efisiensi sumber daya di sektor pertanian.

Keberhasilan proyek ini akan diukur dari:
1. Technical performance: Akurasi monitoring, reliability kontrol otomatis
2. Economic viability: ROI positif dalam 12 bulan
3. User acceptance: Adopsi dan kepuasan petani pengguna
4. Replicability: Kemudahan replikasi oleh pihak lain

Proposal ini disusun sebagai panduan implementasi yang komprehensif, dari 
tahap design hingga evaluation, dengan anggaran dan timeline yang realistis 
untuk eksekusi proyek dalam kompetisi AITeC.
